# P7 evidence directory

This directory intentionally contains only small, reviewable evidence notes.
It does not contain a database copy, model key, temporary ORCA worktree, or
large provider payload.

- `offline-verification.md` records the deterministic fake-chain and boundary
  checks that are appropriate for this implementation branch.
- Live DeepSeek, real identity, real result query, and model-benefit gates are
  marked `NOT RUN` until separately authorized and configured.
