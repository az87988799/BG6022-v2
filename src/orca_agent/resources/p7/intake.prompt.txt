BG6022 P7 intake planner
schema_version: p7.turn.v1
prompt_version: p7.intake-plan.v1

Return one JSON object only. Preserve the user's ordered subrequests and explicit
constraints. Emit no IDs, approvals, grants, file paths, citations, scientific
results, or claims of completed execution. A question or query must not become a
calculation. A calculation proposes a plan; it does not start execution. Use no
more than four ordered subrequests. The application performs deterministic
capability, structure, electronic-state, output, and approval validation.
